# GrowthLoop MVP 验收文档

本文档记录 GrowthLoop Cloud + AI MVP 的当前状态、已完成能力、手动测试清单、已知限制和下一阶段建议。

## 当前 MVP 已完成能力

### 1. 基础架构
- Next.js 15 App Router + TypeScript
- Tailwind CSS 移动端优先工具型扁平风 UI
- 底部导航栏 (Dashboard / Check-in / Review / Goals)

### 2. 双模式数据存储
- **本地模式** (localStorage)：未登录时使用，数据保存在浏览器中
- **云端模式** (Supabase)：登录后使用，数据保存在 Supabase PostgreSQL
- 登录/退出时自动切换数据源
- 已登录不使用 mock 数据或 fallback localStorage

### 3. Supabase Auth
- 邮箱 + 密码注册/登录
- 登录状态持久化
- AuthStatus 组件显示当前用户
- 登录页简洁用户友好

### 4. Goals & Actions
- 创建/删除目标
- 为目标创建可执行行动（支持 minimum/standard 目标量）
- 删除行动
- 目标和行动关联到登录用户 (RLS)

### 5. Daily Check-in
- 记录每日睡眠、精力、心情、压力
- 记录各行动完成状态 (not_started/minimum_met/standard_met/skip/fail)
- 查看当日统计面板
- 数据保存到 Supabase（云端）或 localStorage（本地）

### 6. Dashboard
- 当前目标概览
- 正在执行中的行动列表
- 今日检查状态

### 7. Weekly Review
- 本周数据统计（睡眠均值、精力均值、心情均值、压力均值、行动完成率）
- 问题卡片（高压力、低完成率行动、连续最低完成行动）

### 8. AI Weekly Review (DeepSeek)
- 调用 DeepSeek API 生成个性化周复盘
- 复盘内容：本周概览、关键洞察、成就、挑战、建议
- 保存复盘到 Supabase `weekly_reviews` 表
- 用户可添加反思文本
- 刷新页面后回填已保存的复盘

### 9. localStorage → Cloud 迁移
- 检测本地有数据且已登录时显示迁移卡片
- 一键迁移 goals/actions/dailyLogs/actionRecords
- 迁移后本地数据不清除

### 10. 模式提示
- 各页面显示当前数据模式（本地/云端）
- 未登录：本地模式
- 已登录：云端模式

---

## 核心用户流程

```
1. 首次访问 → 未登录 → 本地模式
   ↓
2. 创建 Goal → 创建 Actions → 每日 Check-in
   ↓
3. 注册/登录 → 云端模式
   ↓
4. 迁移本地数据 → 数据同步到 Supabase
   ↓
5. 在任意设备登录 → 数据一致
   ↓
6. 周末 → 查看 Weekly Review → 生成 AI 复盘 → 保存反思
```

## 已知限制

1. **离线支持**：本地模式依赖 localStorage，云端模式需要网络连接。不支持离线优先自动同步。
2. **数据冲突**：本地和云端数据独立，迁移后本地数据不会自动同步。
3. **多设备**：不支持实时多设备同步（只能通过登录/迁移手动同步）。
4. **AI 复盘**：依赖 DeepSeek API 可用性，API 不可用时无法生成复盘。
5. **历史回顾**：目前仅展示本周数据，不支持查看历史周数据。
6. **性能**：未做分页或虚拟滚动，目标/行动数量过多时可能有性能问题（但当前使用场景下影响很小）。
7. **样式**：仅支持系统亮/暗模式跟随，不支持手动切换。
8. **国际语言**：仅支持中文。

## 不做事项

以下功能在 MVP 阶段明确不做：

- ❌ AI Coach（个性化成长教练对话）
- ❌ 流式 AI 输出
- ❌ 数据可视化图表（趋势图、热力图等）
- ❌ PWA / 离线支持
- ❌ 复杂历史复盘页面
- ❌ Supabase schema 变更
- ❌ DeepSeek 模型配置变更
- ❌ localStorage 模式移除
- ❌ 整体 UI 重构
- ❌ 实时多设备同步
- ❌ 社交分享

## 下一阶段建议

### 短期 (v1.1)
1. **历史周复盘**：支持查看过往周的统计和 AI 复盘
2. **数据导出**：支持导出 CSV/JSON 备份
3. **账号删除**：用户可自行删除账号和数据
4. **密码重置**：通过邮箱重置密码

### 中期 (v1.2)
1. **AI Coach**：接入 DeepSeek 作为成长教练对话
2. **趋势图表**：轻量级数据可视化（7天/30天趋势）
3. **PWA 支持**：基础离线缓存

### 长期 (v2.0)
1. **多语言**：英文支持
2. **团队模式**：共享目标和复盘
3. **更多 AI 集成**：目标分解建议、每日反馈
