# Local MVP 测试清单

本文档用于验证 GrowthLoop 本地 MVP 的功能完整性。
测试环境：`npm run dev` 启动后用浏览器访问 http://localhost:3000。

## 前置条件
- 每次测试前可点击 Goals 页面底部的"清空所有本地数据"重置状态
- 或使用 Chrome DevTools → Application → Local Storage → 删除 `growthloop_*` 开头的 key

## 已知限制
- 不支持多用户，所有数据以 `local-user-001` 存储
- 没有数据加密
- 清除浏览器缓存会删除所有本地数据（请先导出备份）
- 不同设备/浏览器之间数据不会同步
